# 🤖 CopyRealBot

A Telegram bot that cleans text spaces, strips link trackers, and counts ad characters.

## ✨ Features

- ✅ Clean extra spaces from text
- ✅ Remove tracking parameters from URLs (utm_, ref, code, etc.)
- ✅ Count characters with/without spaces
- ✅ Custom welcome message with image
- ✅ Fully compliant with Telegram TOS
